# KeyNub

USB-C security hardware for professional software, developed and supported in
Germany by [AB-Tools GmbH](https://www.keynub.com/).

- **[KeyNub License Dongle](https://www.keynub.com/)**: a hardware license
  dongle that proves a genuine licence is present. The key pair is generated
  inside a secure element and never leaves it; verification is local, so
  licensing works offline and on air-gapped machines. No driver to install on
  Windows, Linux or macOS. [Datasheet (PDF)](https://www.keynub.com/wp-content/uploads/KeyNub-Datasheet.pdf)
  · [Security architecture](https://www.keynub.com/security/)
  · [By industry](https://www.keynub.com/industries/)
- **[KeyNub HSM](https://www.keynub.com/hsm/)**: a USB-C hardware security
  module for PKCS#11 and PKI, with keys generated inside a certified smart card.

## Repositories

- **[KeyNub-SDK](https://github.com/AB-KeyNub/KeyNub-SDK)**: the license
  dongle SDK. One core C library with a stable ABI, bindings and runnable
  samples for [37 languages](https://www.keynub.com/developers/), the prebuilt
  native libraries for every platform, the wire protocol and the security
  documentation. Bindings and samples are Apache-2.0.
